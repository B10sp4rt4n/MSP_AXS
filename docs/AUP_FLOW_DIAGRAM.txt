┌────────────────────────────────────────────────────────────────────────────┐
│ AXIOMA 1: Sin AUP_SESSION válida → 401 Unauthorized                       │

│   ❌ Usuario no existe ──────> 401 "No se pudo validar las credenciales" │

│   ✅ Token válido + Usuario existe ──> Ejecuta acción                     │

│     "iat": 1735459200,     // Emitido: 2025-12-29 00:00:00               │

│   }                                                                         │
│                                                                             │
